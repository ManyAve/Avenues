# Foundations

How to use Avenue's tokens when building ManyAve screens. Each page states the rules in plain sentences, with a do
and a don't drawn from screens the app has today. The values themselves live under Tokens; these pages don't repeat
them.

- **Color**: what each status colour means, and why colour never carries meaning alone.
- **Typography**: which step to use where, on the web and desktop scales, and the 14px floor.
- **Spacing**: the six spacing names, one height per row of controls.
- **Radius**: which corner, rounded things inside rounded things, where pills go, and the year select in the Dues card.
- **Elevation**: three shadows and what each says.
- **Icons**: one set, four sizes, always with a word.
- **Motion**: short, triggered by the person, and off when Reduce motion is on.
- **Theming**: name a role, not a colour, so light and dark both work.
- **Native apps**: what the iPhone and Android apps take from Avenue, and the platform control for each component.
- **Agents**: how a component stays usable by an agent, with the agent test to copy.
- **Moving from older tokens**: for an app on an older copy of the shared tokens, which sizes grow and which dark colours moved.

Switch the toolbar between light and dark, and between the web and desktop type scales. All examples use fictional
households.
