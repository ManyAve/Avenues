# Tokens

Colour, type, spacing, radius and elevation values. Every other section is built from these.

The colour, type and shadow values are copied from ManyAve Management, so Avenue looks like the app. Two dark fills
are slightly darker so their text is readable (info and destructive). Spacing, control heights and corners follow
Avenue's spacing and corner rules: one 4px grid, four control heights, five corner steps.

Apps whose cards carry no border can opt into lifted surfaces with `data-surface="lifted"` on `<html>`: a tinted
page under white cards, and fills that show on a card (Tokens/Surfaces).

Use the toolbar to switch between light and dark, between the web and desktop type scales, and between the default
and lifted surfaces.
